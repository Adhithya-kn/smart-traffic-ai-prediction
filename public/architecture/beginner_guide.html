The 4 Core Engineering Ingredients

Everything you need to know about the stack in plain English

CORE LANGUAGE

Python 3.11 + Vanilla JS

Backend: Python · Frontend: ES6 JS + CSS3

Zero bloated front-end frameworks like React or Angular. Clean, ultra-fast Python on the server, paired with human-crafted CSS and vanilla JavaScript that renders in milliseconds.

Why this matters: Starts up in under 50ms, consumes virtually no memory, and never suffers from JavaScript library dependency rot.
DATABASE & STORAGE

Crash-Proof Atomic JSON

POSIX Two-Phase fsync Commit + 57.6k Kaggle CSV

Instead of running a heavy SQL server that can corrupt during power loss, state lives in clean JSON files (events.json, users.json) protected by two-phase write + os.fsync + rename.

Why this matters: If someone pulls the power plug mid-write, your data is 100% safe. Zero half-written or corrupted records ever.
SERVER FRAMEWORK

Zero-Dependency HTTP

Python ThreadingHTTPServer + Vercel Edge WSGI

No heavy Django or Flask dependencies. Built directly on Python's built-in http.server.ThreadingHTTPServer for local and Render Docker, with an edge serverless wrapper for Vercel.

Why this matters: Zero external web framework overhead. Boots up instantly on cloud edge servers anywhere in the world.
AI & PHYSICS MODELS

XGBoost + Webster Timing

XGBoost (73.56% Acc) + Greenshields Physics

Combines a calibrated XGBoost Multi-Class Classifier (predicts: Low, Moderate, High, Severe) with 70-year proven traffic physics: Greenshields continuity ($q = kv$) and Webster's signal cycle formula.

Why this matters: The AI predicts when jams will happen; the traffic physics engine calculates how many seconds of green light to give.

The 5-Step Dataflow: From Road Sensors to Driver Screen

A step-by-step walkthrough of what happens under the hood

STEP 01

Data Ingestion & Live GPS Probing

The system gathers baseline traffic metrics from 57,600 Kaggle dataset records and polls TomTom GPS probe speeds and Open-Meteo rainfall telemetry.

Code & Modules Involved

traffic_system/live/bridge.py
Cached in-memory with 120s TTL and token-bucket limiter to guarantee zero API quota exhaustion.

STEP 02

Spatio-Temporal Feature Encoding

Raw numbers are cleaned and packaged into 7 distinct features: vehicle count, average speed, road capacity utilization %, hour of day, day of week, and weekend flag.

Code & Modules Involved

traffic_system/models/predictor.py
Column transformer encodes categorical road zones and scales numeric features to match training bounds.

STEP 03

AI Forward-Horizon Prediction

The XGBoost classifier evaluates the feature vector and outputs class probabilities for 4 congestion levels: Low, Moderate, High, or Severe for the next time interval.

Code & Modules Involved

traffic_system/models/strategies/
Also computes Shannon entropy to verify model confidence (eliminating hallucinated predictions).

STEP 04

Incident Matching & Dynamic Bypass Rerouting

The navigator checks events.json for nearby construction, accidents, or waterlogging using Haversine distance (≤ 1.8km). If a road is blocked, it calculates a bypass.

Code & Modules Involved

traffic_system/routing/navigator.py
Dijkstra shortest-path algorithm evaluates travel times and calculates the net minutes saved by taking the detour.

STEP 05

Municipal Actuation & Visual Display

Drivers see comparison cards with the fastest route and time saved. Traffic police receive Webster green light timing adjustments and electronic roadside sign messages.

Code & Modules Involved

traffic_system/simulation/signal_optimizer.py
Actuates Webster's minimum delay formula ($C_0$) to balance green times across conflicting intersection phases.

Beginner's No-Jargon Cheat Sheet

Every technical term explained in simple human words

XGBoost Machine Learning

Imagine 100 mini-detectives (decision trees) who all look at traffic numbers and vote on whether the road will be clear or jammed. XGBoost is the boss who listens to all 100 detectives and makes the final call.

POSIX Atomic Write Storage Safety

Instead of scribbling directly into the master notebook where a sudden power cut might leave a half-finished mess, the computer writes on a clean scratchpad first. When finished, it swaps the pages in one instant blink.

Webster's Formula Traffic Signals

A famous mathematical equation from 1958 ($C_0 = \frac{1.5L + 5}{1 - Y}$) that calculates the exact number of seconds a traffic light cycle should last to keep car queues as short as mathematically possible.

Haversine Distance GPS Math

Because the Earth is a curved sphere rather than a flat sheet of paper, straight-line ruler math doesn't work. Haversine calculates true GPS distance across the curve of the Earth to see if an incident is near a road.

Judea Pearl do-calculus Causal Simulation

Instead of guessing, Pearl's math allows city planners to simulate "What if we do X?" inside a computer (e.g., what if 20% of cars stay home?) and observe the true domino effects without experimenting on real drivers.

Level of Service (LOS) Traffic Grades

Think of it as school report cards for roads: LOS A is free-flowing and fast (an 'A' student), while LOS F is total bumper-to-bumper standstill breakdown (an 'F' grade).
