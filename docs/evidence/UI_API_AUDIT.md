## (c) Remove / rewire

**Remove (not in problem statement):** whole **API & System Synthesizer** tab (handshake, POSIX/snapshot storage, synthetic stream, sandbox — dev tooling, currently contradictory); "Live Grid" synthetic scenarios/disruption presets/"sync live feeds" (backend is not live); specular/haptic/audio chrome (`app.js:92-167`, beeps on every tab/switch); dead Live-CCTV code (`app.js:5123-5135`, `5505`, `5734`, `5798`, `/api/vision/live/frame`); "Indo-HCM" bicycle/auto PCU rows (detector classes are car/motorcycle/bus/truck only, `vision_routes.py:495`).

**Rewire to CV-first vision:** make Vision AI the primary flow — add a 1-click "run `sample_traffic.mp4`/`sample_north_east.mp4`" button and a working no-login/demo path (auto session must be a real server token or removed); rename "Closed-Loop Grid Actuation" → "Signal-timing recommendation (advisory)" and feed real vision metrics (endpoint accepts `{vision_metrics:{}}` and fabricates `calibrated_speed_kmh:28.0` etc., `vision_routes.py:630`); label "XGBoost 1h horizon" (or train a real 15-min model); label tracker "custom IoU"; surface detection-accuracy metrics (problem statement item 6 — only "Forecast Accuracy 87.0%" exists, no mAP/precision/recall anywhere in UI); implement heat overlay with weighted circles/polylines since Google HeatmapLayer is removed.
